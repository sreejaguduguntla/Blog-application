# Blog App Frontend

Frontend for the Full Stack Blog Application built using React and Vite.

This frontend provides:

- Authentication pages
- User and Author dashboards
- Article management UI
- Comments system
- Protected routes
- Session persistence
- Responsive layouts
- Toast notifications
- API integration with backend

---

# Frontend Tech Stack

- React 19
- Vite
- React Router DOM
- Tailwind CSS
- Zustand
- Axios
- React Hook Form
- React Hot Toast

---

# Frontend Development Process

- Created React app using Vite
- Organized folder structure
- Configured routing using React Router
- Designed reusable UI components
- Connected frontend with backend APIs using Axios
- Added Zustand for global state management
- Implemented authentication handling
- Added protected routes
- Designed dashboards for:
  - Users
  - Authors
- Added toast notifications
- Implemented responsive UI using Tailwind CSS
- Configured deployment using Vercel

# API Connection

Axios is used for API requests.

Backend APIs are connected using:

```js
axios.get()
axios.post()
axios.put()
axios.patch()
```

with credential-based authentication.

# How To Run Frontend

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
